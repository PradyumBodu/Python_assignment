1. Introduction to Loops in Python
->  Loops are used to repeat a block of code multiple times until a certain condition is met.

There are two main types of loops in Python:

    i. for loop – used to iterate (go through) a sequence like a list, string, or range.

    ii. while loop – used to repeat code while a condition is true.

--------------------------------------------------------------------------------------------------------------


2. How Loops Work in Python
-> For Loop :
Used when you know how many times you want to repeat.

Syntax:
    for variable in sequence:
        # code to repeat

-> While Loop :
Used when you want to repeat until a condition becomes false.

Syntax:
    while condition:
        # code to repeat

-----------------------------------------------------------------------------------------------------------------------

3. Using Loops with Collections
-> Collections = Lists, Tuples, Sets, Dictionaries, Strings, etc.

=> Loop through a List:
    fruits = ["apple", "banana", "cherry"]
    for fruit in fruits:
        print(fruit)
    
    Output:
        apple
        banana
        cherry

=> Loop through a Tuple:
    colors = ("red", "green", "blue")
    for c in colors:
        print(c)

=> Loop through a String:
    for ch in "HELLO":
        print(ch)

=> Loop through a Dictionary:
    student = {"name": "Pavan", "age": 22, "course": "Python"}
    for key, value in student.items():
        print(key, "=", value)


=> Using while Loop with Collections
You can also use while with collections using indexes:

fruits = ["apple", "banana", "cherry"]
i = 0
while i < len(fruits):
    print(fruits[i])
    i += 1
