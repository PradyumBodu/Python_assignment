1. The break Statement
-> Used to exit (stop) a loop immediately, even if the condition is still true.

It is often used when you find what you’re looking for and no longer need to continue looping.

Example:

for i in range(1, 6):
    if i == 3:
        break  # stop loop when i = 3
    print(i)


Output:
1
2

Loop stops when i becomes 3.

----------------------------------------------------------------------------------------------------------------------------------------

2. The continue Statement
-> Used to skip the current iteration and move to the next one.

The loop doesn’t stop, it just skips that one turn.

Example:

for i in range(1, 6):
    if i == 3:
        continue  # skip printing 3
    print(i)


Output:
1
2
4
5
When i = 3, that iteration is skipped.

---------------------------------------------------------------------------------------------------------------------------------------

3. The pass Statement
-> Used as a placeholder.

It does nothing, but allows the code to run without error when a statement is syntactically required.

Example:

for i in range(1, 6):
    if i == 3:
        pass  # do nothing for i = 3
    print(i)


Output:
1
2
3
4
5

When i = 3, nothing happens — it just continues normally.
