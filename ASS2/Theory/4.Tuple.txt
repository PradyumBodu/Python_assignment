1. Introduction to Tuples
-> A tuple is a collection of items like a list, but immutable (cannot be changed after creation).

Tuples are defined using parentheses ().

# Creating a tuple
my_tuple = (10, "Hello", 3.14, True)
print("Tuple:", my_tuple)

Output:
Tuple: (10, 'Hello', 3.14, True)

Immutability:
You cannot add, remove, or change elements once a tuple is created.

--------------------------------------------------------------------------------------------------------------------------------


2. Creating and Accessing Elements in a Tuple
-> Access elements using indexing
# Positive indexing
print("First element:", my_tuple[0])
print("Third element:", my_tuple[2])

# Negative indexing
print("Last element:", my_tuple[-1])
print("Second last element:", my_tuple[-2])

Output:
First element: 10
Third element: 3.14
Last element: True
Second last element: 3.14

Slicing a tuple
print("Elements from index 1 to 3:", my_tuple[1:3])
print("Elements from start to index 2:", my_tuple[:2])
print("Elements from index 2 to end:", my_tuple[2:])

Output:
Elements from index 1 to 3: ('Hello', 3.14)
Elements from start to index 2: (10, 'Hello')
Elements from index 2 to end: (3.14, True)

3. Basic Operations with Tuples
-> a) Concatenation (+)
Combine two tuples.

t1 = (1, 2, 3)
t2 = ("a", "b")
t3 = t1 + t2
print("Concatenated tuple:", t3)

Output:
Concatenated tuple: (1, 2, 3, 'a', 'b')


b) Repetition (*)
Repeat elements of a tuple.

t = (1, 2)
print("Repeated tuple:", t * 3)

Output:
Repeated tuple: (1, 2, 1, 2, 1, 2)


c) Membership (in)
Check if an element exists in a tuple.

fruits = ("apple", "banana", "cherry")
print("Is 'banana' in tuple?", "banana" in fruits)
print("Is 'orange' in tuple?", "orange" in fruits)

Output:
Is 'banana' in tuple? True
Is 'orange' in tuple? False
