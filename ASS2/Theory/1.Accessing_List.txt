1. Creating a List
-> A list in Python is a collection of items (can be numbers, strings, or even other lists) enclosed in square brackets [].

# Example of a list

fruits = ["apple", "banana", "cherry", "date", "elderberry"]
print(fruits)

----------------------------------------------------------------------------------------------------------------------------------


2. Accessing Elements Using Indexing
-> Each element in a list has an index. Indexing starts from 0 for the first element.

Positive Indexing :
print(fruits[0])  # first element
print(fruits[2])  # third element

Output:
apple
cherry

Negative Indexing :
Negative indexing starts from -1 (last element) and goes backward.

print(fruits[-1])  # last element
print(fruits[-3])  # third last element

Output:
elderberry
cherry

---------------------------------------------------------------------------------------------------------------------------

3. Slicing a List
-> Slicing allows you to access a range of elements. The syntax is:

list[start:stop:step]

start → index to start (inclusive)

stop → index to stop (exclusive)

step → step size (optional, default is 1)

Examples
# Access elements from index 1 to 3 (excluding index 3)
print(fruits[1:3])

Output:
['banana', 'cherry']

# Access from start to index 2 (excluding 2)
print(fruits[:2])

Output:
['apple', 'banana']

# Access from index 2 to the end
print(fruits[2:])

Output:
['cherry', 'date', 'elderberry']

# Access every 2nd element
print(fruits[::2])

Output:
['apple', 'cherry', 'elderberry']

# Reverse the list
print(fruits[::-1])

Output:
['elderberry', 'date', 'cherry', 'banana', 'apple']
